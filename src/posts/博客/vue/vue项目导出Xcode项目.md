# vue 导出导出 xcode 项目

## 1.安装 node

```
brew install node
```

## 2.查看版本

```
node -v
npm -v

```

## 3

```
npm run build
```

## 4.安装 cordova

```
npm install -g cordova

cordova -v
```

## 5

```
cordova create  Project-CordovaDemo
```

## 6

```
cd Project-CordovaDemo
1.  cordova build ios
2.  cordova platform add ios
3.  npm install -g ios-deploy
4.  cordova build ios
```
