# 关于我和这个博客

## 我是谁

daisz，一个喜欢写写东西、折腾技术的普通人。

主要关注的方向是移动端开发，也会涉猎前端框架和后端技术。平时对AI工具比较感兴趣——不是为了追热点，是真的觉得这些工具能提高效率、改变做事的方式。

## 博客里有什么

这个博客大概分八个板块，也是我生活的八个切面：

- **生活随笔**：记录日常的感悟、家庭、一些真实的情绪。像[致奋斗中的自己](/posts/生活随笔/致奋斗中的自己.md)、[被勾起的开封回忆](/posts/生活随笔/被勾起的开封回忆.md)这些，都是某个时刻的真实书写
- **旅行游记**：走过的地方，看过的风景。西安、济南、洛阳、郑州周边，攻略和个人体验都有
- **汽车世界**：从选车、买车到练车，一个新手司机的成长记录
- **AI与创作**：折腾各种AI工具的尝试和心得
- **实用推荐**：生活妙招、电影观后感、健身计划这些杂七杂八但实用的东西
- **工具收藏**：好用的在线工具导航和体验
- **技术博客**：编程相关的学习笔记，Spring、iOS、Vue、Flutter、鸿蒙都有涉猎
- **游戏天地**：偶尔放松一下的记录

## 为什么写博客

这个问题我在[随笔的意义](/posts/生活随笔/随笔的意义.md)里聊过。简单说：宁可不发，也不复制粘贴凑数。这里的每一篇文章，要么是我真正学到的东西，要么是我真实经历的事情。

写博客对我而言，是学习的输出口，也是给未来的自己一个回顾的入口。偶尔翻翻自己以前写的文章，会有一种"原来我当时是这样想的"的奇妙感。

欢迎交换友链，可通过 GitHub 联系我。
